Receitas Vascainas

Descrição

Funcionalidades

Carregamento e listagem de receitas.

Pesquisa de receitas pelo nome.

Visualização de ingredientes e instruções de preparo.

Adição e remoção de receitas favoritas.

Armazenamento de favoritos em memória durante a sessão.

Tratamento de erros e opção de nova tentativa.

Indicadores de carregamento.

Tratamento de falhas no carregamento de imagens.

Dependências

Flutter Material: construção da interface.

http: realização de requisições HTTP.

flutter_test: execução de testes automatizados.

SDK e tecnologias utilizadas

Flutter SDK

Dart SDK

API REST DummyJSON Recipes

Documentação da API: https://dummyjson.com/docs/recipes

Instruções de execução

Instale o Flutter SDK.

Clone o repositório.

Acesse a pasta do projeto pelo terminal.

Instale as dependências:

flutter pub get

Execute o aplicativo:

flutter run
